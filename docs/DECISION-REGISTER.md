# MylesNet Decision Register

**As of:** 13 November 2026

**Plan phase:** Phase 0 — close planning and turn decisions into build contracts

**Status:** Baseline reconciled; open evidence, owner, and implementation-contract work remains.
**Scope:** This register records approved v1 direction, candidates that are not production approvals, and decisions/evidence still open. It does not authorize product implementation, live integrations, service provisioning, or deployment.

## Authority and maintenance

Use the project charter in [`AGENTS.md`](../AGENTS.md) and approved decisions in [`READINESS-DECISIONS.md`](READINESS-DECISIONS.md) as the decision authority. [`TECH-STACK.md`](TECH-STACK.md) consolidates the selected technical direction. [`IMPLEMENTATION-PLAN.md`](IMPLEMENTATION-PLAN.md) is the execution sequence and acceptance authority. Older proposal text is historical context only after it is marked superseded or reconciled here and in its canonical document.

**States:** `Approved` means approved v1 direction; it is not evidence of implementation. `Candidate` means a leading option that still requires the listed validation. `Open` means no value or approval has been supplied; do not infer one. `Rejected` is reserved for an option explicitly ruled out by an approved decision.

No individual owners are named for the open commercial, legal, provider, design-system, and operations work. The owner column records that gap instead of assigning it by assumption. MN-PLAN-008 established the role-level baseline; the [Phase 0 owner appointment and sign-off register](PHASE-0-OWNER-APPOINTMENT-REGISTER.md) provides a worksheet for recording individual appointments and review evidence. The project owner must still fill and validate it before Phase 0 exit.
